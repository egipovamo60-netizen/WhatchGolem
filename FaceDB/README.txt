  └── _embeddings_cache.json   (создаётся автоматически)

Как добавить человека:
  1. Создайте папку с именем человека (пробелы заменяйте на _)
  2. Положите в неё одно или несколько фото с лицом

  Или через утилиту:
    python manage_face_db.py add "Иван Петров" path/to/photo.jpg

Команды утилиты:
  python manage_face_db.py add "Имя" photo.jpg   — добавить фото
  python manage_face_db.py list                   — список всех людей
  python manage_face_db.py remove "Имя"           — удалить человека
  python manage_face_db.py rebuild                — пересоздать кэш

Примечания:
  • Чем больше фото одного человека (разные ракурсы, освещение),
    тем точнее будет распознавание.
  • Поддерживаемые форматы: JPG, JPEG, PNG, BMP
  • Кэш эмбеддингов создаётся автоматически при первом анализе.
    После добавления новых фото кэш обновится автоматически.
