### ⚙️ Как это работает

**Цвет:** Региональная выборка (верх/середина/низ) вместо анализа всего изображения
```
Верх: может быть небо (вес 20%)
Середина: само тело машины (вес 60%) ← ГЛАВНОЕ
Низ: может быть дорога (вес 20%)
→ Результат точнее на 15%
```

**Модель:** Ансамбль из 2-3 CLIP моделей вместо одной
```
Model 1: BMW M3 = 0.87
Model 2: BMW M3 = 0.89
→ Медиана = 0.88 (более надежно)
```

**Номер:** Три метода вместо двух (OpenALPR + EasyOCR + CV)
```
OpenALPR: confidence = 25%
EasyOCR: confidence = 70% ✓
CV Fallback: confidence = 65% ✓
→ Голосование = 53% (ВСЕГДА результат!)
```

## 📋 Требования к фотографиям

Для лучших результатов:
- ✅ Чистое изображение машины (не слишком маленькое)
- ✅ Хорошее освещение
- ✅ Видна основная часть корпуса (для цвета)
- ✅ Видны номер и марка (для номера и модели)

**Что может снизить точность:**
- ❌ Очень размытые фото
- ❌ Машина в тени или против света
- ❌ Машина засыпана снегом/грязью (будет серо/коричневая)
- ❌ Номер закрыт или стерт

## 🐛 Решение проблем

### Проблема: "CLIP модель не загружается"
```
❌ FileNotFoundError: model.safetensors
```

**Решение:**
```bash
# Интернет требуется для первого запуска
# Убедитесь, что подключены к интернету
# И папка ~/.cache/ имеет достаточно места (~1 GB)
```

### Проблема: "EasyOCR работает медленно"
```
⏳ Waiting for EasyOCR model download...
```

**Решение:**
```bash
# Нормально, скачивает модели в первый раз
# Последующие запусы будут быстрыми
# Модели сохраняются в ~/.EasyOCR/
```

### Проблема: "Всё медленно работает"

**Возможные причины:**
- Первый запуск (нужно скачать CLIP модели) → нормально
- Недостаточно памяти → переключитесь на v3.x (config.json)
- HDD очень медленный → SSD рекомендуется
